# 宝塔面板安装与授权说明

完整客户步骤见安装包内 **install-guide.md**。  
卖家打包与发卡见 **[卖家打包与发卡.md](./卖家打包与发卡.md)**。

---

## 卖家（你）

1. 本机设置 `LICENSE_SECRET`，运行 `.\scripts\pack_customer.ps1` 得到 zip  
2. 把 zip 发给客户（不要发完整仓库、不要发 `gen_license.mjs`）  
3. 客户告知域名后：

```powershell
$env:LICENSE_SECRET="与打包时相同"
node scripts/gen_license.mjs --domain=客户域名.com --days=365
```

---

## 客户（摘要）

1. 宝塔安装 Nginx + Node 20+  
2. 解压到 `/www/wwwroot/ea-monitor`  
3. `bash install.sh`  
4. 反代到 `127.0.0.1:8787`，开 HTTPS  
5. 粘贴授权码激活 → 用 `.env` 的 `ADMIN_TOKEN` 登录（账号默认 `admin`）

客户包内详细步骤：`install-guide.md`。

---

## 授权范围

`LICENSE_ENFORCE=1` 时：未激活 / 域名不符 / 过期 → 不能登录、不能收 EA、分享不可用。

你自己的演示站可继续 `LICENSE_ENFORCE=0`。

---

## 注意

- 客户包内含同一把 `LICENSE_SECRET` 才能离线验签；勿公开传播密钥  
- 换密钥必须重新打包；旧码只对旧密钥有效  
- 更强保护可后续做「在线激活服务器」
