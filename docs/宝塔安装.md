# 宝塔面板安装（开源自建）

把本仓库部署到自己的服务器，即可拥有和 [688118.xyz](https://688118.xyz/) 同类的 EA 监控站。  
**无需授权码，开箱即用。**

## 环境

- Linux VPS（推荐 Ubuntu 22+）
- 宝塔面板：Nginx + Node.js **20+**
- 域名解析到服务器（可选 HTTPS）

## 步骤

### 1. 拉取代码

```bash
cd /www/wwwroot
git clone https://github.com/JustinaHodges/ea-monitor.git
cd ea-monitor/server
```

### 2. 配置环境变量

```bash
cp .env.example .env
nano .env
```

至少修改：

```env
ADMIN_TOKEN=换成你自己的长密码
LICENSE_ENFORCE=0
```

`LICENSE_ENFORCE=0` 表示关闭授权校验（开源默认就是这样）。

### 3. 安装依赖并启动

```bash
npm install
# 可用 pm2 或 systemd 常驻，例如：
npm start
```

默认监听 `127.0.0.1:8787`。

systemd 示例单元见仓库 `deploy/ea-monitor.service`（按实际路径改 `WorkingDirectory`）。

### 4. Nginx 反代

参考 `deploy/nginx-customer.conf.example`：把域名反代到 `http://127.0.0.1:8787`，并配置 SSL。

### 5. 登录

浏览器打开你的域名，用 `.env` 里的 `ADMIN_TOKEN` 作为管理员密码登录（默认账号 `admin`，可在后台改）。

### 6. 对接 EA

把 `mql/` 里的监控 EA 装到 MT4/MT5，API 地址填你的站点域名（不要末尾斜杠），填入后台生成的实例 ID 与密钥。

## 本地开发（可选）

```bash
cd server
cp .env.example .env
npm install
npm start
```

打开 http://localhost:8787

更多说明见 [server/README.md](../server/README.md)。
